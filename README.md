# Road Safety in Bulgaria: Statistical Analysis of Exposure and Fatalities

This project investigates the relationship between exposure indicators and road fatalities in Bulgaria using a data-driven analytical approach.

The analysis integrates Bulgarian and European road safety datasets and applies data preprocessing, normalization, visualization, and statistical analysis techniques.

The study focuses on:
- exploratory data analysis,
- normalized fatality indicators,
- exposure proxy interpretation,
- and statistical association analysis using Pearson correlation.

Due to the absence of aggregated national traffic intensity data, population is used as a proxy variable for exposure. Therefore, the analysis focuses on statistical associations rather than causal inference.

## Project Scope

The project includes:
- data cleaning and preprocessing,
- feature engineering,
- exploratory data analysis (EDA),
- statistical analysis,
- comparative benchmarking against EU fatality indicators,
- and methodological discussion of limitations and uncertainty.
